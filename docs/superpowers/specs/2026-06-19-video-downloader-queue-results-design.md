# 视频下载队列结果与切片并发配置设计

## 目标

在不大幅调整 FireflyTools 现有界面的前提下，为视频下载爬虫增加可编辑的切片并发数，并在一批等待队列任务全部处理完成后统一显示成功、失败结果。失败任务可一键按原配置重新加入队列。

## 范围

本次只修改视频下载爬虫模块及其必要测试，不调整其他三个工具页面，不改变主窗口、壁纸主题、下载页容器宽度、日志区域和主要按钮布局。

## 界面与交互

1. 在“保存位置”下方增加“切片并发数”一行，使用 `QSpinBox`，取值范围为 1–100。
2. 应用启动时保持当前默认的低速稳定模式，并将并发数显示为 5。
3. 切换到高速爆发模式时，并发数自动设为 30；切回低速稳定模式时自动设为 5。
4. 模式切换后，用户仍可手动修改并发数。再次切换模式时，输入框恢复为新模式对应的默认值。
5. 高速/稳定模式继续控制现有超时、重试次数和退避延迟策略，同时保留原先 30/5 的默认并发行为。
6. 添加任务时，将当时的 URL、名称、保存目录、模式和并发数一并保存。之后修改界面不会改变已排队任务。
7. 等待队列文字增加并发信息，例如：`[稳定 / 5并发] my_video_01 -> https://...`。

## 下载与结果判定

沿用当前单一后台队列线程：不同视频任务仍按入队顺序逐个处理，每个 M3U8 视频内部使用任务保存的并发数限制同时下载的切片数量。

`UniversalVideoSpider` 接收显式的切片并发数，并为一次下载返回可判定的成功结果，或抛出包含原因的异常。以下情况判定为失败：

- 网页嗅探结束后没有找到可用视频流；
- MP4 或 M3U8 请求失败；
- 任一切片在既定重试次数后仍下载失败；
- 初始化片段获取失败，导致 fMP4 无法可靠合并；
- FFmpeg 合并或容器修复失败；
- 最终输出文件不存在或大小为零。

失败原因写入运行日志，并保存到本批次结果中。失败任务即使产生了不完整输出，也不计为成功；后续重试允许覆盖同名输出文件。

## 批次汇总与重试

后台队列线程维护当前批次的成功和失败结果。一个批次从空队列接收首个任务开始，直到该批次的所有任务均已调用 `task_done()` 且等待队列为空为止。处理期间继续加入的任务归入当前批次。

批次结束后，后台线程通过 Qt 信号把结果传回主线程，由主线程显示一次汇总对话框。对话框显示成功数、失败数、对应任务名称以及失败原因摘要。

- 全部成功时只提供“关闭”。
- 存在失败时提供“重试全部失败任务”和“关闭”。
- 选择重试后，仅把失败任务按原 URL、名称、保存目录、模式和并发数重新加入队列；这些任务构成新批次。
- 成功任务不会重复执行。

所有 QWidget 和 QMessageBox 操作均只在 Qt 主线程执行；后台线程只负责下载、结果累计和发射信号。

## 代码边界

- `UniversalVideoSpider`：执行单个视频下载、应用切片并发限制、向调用方报告明确成功或失败。
- `VideoDownloaderTool`：收集输入、创建队列任务、处理模式默认值、累计批次结果、显示汇总并重试失败项。
- 测试代码：验证纯任务/结果行为与必要的 Qt 控件交互，不依赖真实网络、Playwright 或 FFmpeg。

为了控制改动范围，不引入新的下载控制器、不把现有线程迁移为 `QThread`，也不重做队列列表模型。

## 错误处理

下载层不得再仅记录关键错误后静默返回。影响最终完整性的错误必须传播给队列工作线程，由工作线程记录失败结果。清理临时文件时使用保护性处理，清理失败写入日志但不得覆盖原始下载失败原因。

汇总信号或弹窗不会中断后台线程生命周期；弹窗关闭后，工作线程继续等待下一批任务。

## 测试与验收

自动测试至少覆盖：

1. 默认稳定模式显示并发数 5，高速/稳定切换分别恢复 30/5。
2. 用户自定义的并发数被复制到任务，并传入下载器。
3. M3U8 信号量使用任务指定的并发数，而非硬编码值。
4. 成功输出、嗅探失败、切片缺失、合并失败和空输出能够得到正确结果。
5. 多个任务只在队列完全结束后产生一次批次汇总。
6. “重试全部失败任务”只重新加入失败项，并保留原任务配置。

手动验收包括：

- 下载页只新增一行控件，容器宽度、按钮区、队列区和日志区保持现有视觉结构；
- 数字输入框使用全局主题样式，与 `QLineEdit` 的圆角、边框和文字颜色一致；
- 汇总弹窗从主线程显示，成功批次无重试按钮，失败批次可一键重试；
- 其他三个核心功能页可正常打开且布局未变化。

## 非目标

- 同时处理多个视频任务；
- 为单个失败切片提供界面级选择；
- 勾选部分失败任务重试；
- 下载暂停、取消、进度条或历史记录；
- 大范围重构下载器或全局 UI。
