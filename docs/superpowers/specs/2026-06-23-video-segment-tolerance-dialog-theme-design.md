# 视频切片容错与结果对话框主题修复设计

## 目标

修复视频爬虫在少量切片下载失败时过早判定整个任务失败的问题，并让队列结果对话框与 FireflyTools 的动态明暗主题保持一致。

## 切片容错规则

切片下载完成后，使用精确比例判断是否允许继续：

```text
失败切片数 ÷ 总切片数 ≤ 3%
```

实现时使用整数比较 `失败数 × 100 ≤ 总数 × 3`，避免浮点误差。“不超过”包含恰好 3% 的边界。

- 容错示例：100 个切片失败 3 个、200 个切片失败 6 个，均允许继续。
- 失败示例：100 个切片失败 4 个、200 个切片失败 7 个，任务失败。
- 总切片数为 0 时不进入比例容错，沿用“没有有效切片”的失败结果。

下载阶段和合并阶段必须使用同一个判定函数，避免下载阶段允许后又被合并阶段拒绝。容忍范围内记录包含失败数、总数和比例的警告日志，并仅合并实际下载成功的切片。

切片比例合格只代表允许尝试合并。若没有任何有效切片、FFmpeg 合并失败或最终输出不存在/为空，任务仍判定为失败并进入现有重试流程。

## 结果对话框主题

保留现有 `QMessageBox` 结构、汇总内容和“重试全部失败任务”按钮，不改交互流程。

在动态全局样式中增加 `QMessageBox` 专用规则：

- 对话框背景使用根据壁纸明暗计算出的不透明主题背景色；
- 对话框标签文字使用现有 `text_color`；
- 标签背景透明；
- 按钮继续复用现有主题按钮颜色、悬停颜色和字体颜色。

不使用固定白色或固定黑色，确保切换壁纸后对话框仍保持足够对比度。

## 代码边界

- `tools/video_downloader.py`：新增统一的切片失败比例判定，并在下载和合并阶段复用。
- `tools/theme_utils.py`：生成 `QMessageBox` 背景与文字样式。
- `tests/test_video_downloader.py`：覆盖低于、等于和高于 3% 的边界及合并阶段容错。
- `tests/test_theme_utils.py`：覆盖结果对话框背景与文字主题规则。

不调整并发数、模式切换、队列批次、重试逻辑和其他三个工具页面。

## 验收标准

1. 失败比例小于或等于 3% 时，下载阶段不会因少量失败切片抛出错误。
2. 失败比例大于 3% 时，任务仍明确失败。
3. 合并阶段对相同比例得出相同判定，并只把有效切片交给 FFmpeg。
4. FFmpeg 或输出验证失败不会被比例容错掩盖。
5. 深色和浅色主题生成的 `QMessageBox` 样式均具有匹配的背景与可读文字。
6. 既有队列、并发和重试测试继续通过。
